## Build With
This project is built with React.js & Laravel (API Driven)
- React vite v19
- Laravel v12
- Tanstack Query v5
- Shadcn v3.4
- Zod v4
- MySQL 8.3
- Docker as Containerization
- and more.

## Getting Started
To run the project, ensure that Docker is installed on your local machine, then follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/threeanra/mobo-analyzer.git
    ```
2. Navigate to the project directory:
    ```sh
    cd mobo-analyzer
    ```
3. Build and run the services using Docker:
    ```sh
    docker-compose up --build
    ```
